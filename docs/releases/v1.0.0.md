**nuza still works with no account, and now there is nothing to sign up for.**

This release adds an optional AI panel, off until you turn it on in Settings → AI, that uses an agent you already have: Claude Code, Codex, OpenCode, or any program that speaks the Agent Client Protocol. It runs on your own plan. nuza runs no model, holds no key and has no server. Nothing starts until you turn an agent on in Settings → AI and agree to a notice saying what it will be sent.

## AI

- **Ask about a note** with ⌘L (Ctrl+L on Windows and Linux). The note, and what you selected, go along with your question.
- **Writing actions**: rephrase, a synonym for a word, explain a passage in the context of the note, explain the whole note, proofread, and improve the writing. Use `/` in the panel or the chips above it.
- **Suggested edits, never silent ones.**
  - Changes come back as a diff in the note, for you to accept or reject one by one.
  - Accepting one is an ordinary edit, and ⌘Z undoes it.
- **Search your vault**: the agent can find and read other notes in the folder through nuza's read-only tools. It cites them, and a citation opens the note at the paragraph.
- **Chats you can go back to**: each folder keeps its chats on this computer for a week, a click away in the panel.
- **Memory and your own instructions**:
  - `/remember` keeps short facts per folder.
  - Settings → AI → How it replies sets how answers should read.

## Fenced in

The agent cannot change your files, and cannot read outside what nuza sends it:

- **Every request to act is refused, and the panel says so.** That covers running a command, writing or deleting a file, and a web lookup unless you allow lookups for that folder.
- **The operating system fences it in:** Seatbelt on macOS, and Landlock on Linux 5.13 or newer.
  - It cannot read your home folder, so not your notes and not `~/.ssh`.
  - It cannot write anywhere except its own sign-in and cache folders.
  - Windows has no such fence, and the notice says so before anything starts.
- **Turning AI off** stops the agent and closes nuza's local port.

How it works, exactly what is sent, and the two risks that remain: [nuza.org/docs/ai](https://www.nuza.org/docs/ai).
